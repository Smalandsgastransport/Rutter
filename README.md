# Min rutt

Chaufförsapp för Småländska Bränslens flaktransporter. Visar dagens utskickade rutt per bil och godsdeklarationerna som PDF.

- Planeringen görs i Rutt Planering. Bara rutter som skickats ut där publiceras hit.
- data/index.json listar bilar och dagar. data/<datum>/<bil>.json är rutten, PDF:erna ligger i data/<datum>/<bil>/.
- Installera på iPad: öppna adressen i Safari, Dela, Lägg till på hemskärmen.
